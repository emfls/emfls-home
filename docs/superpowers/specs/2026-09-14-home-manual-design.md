# home.emfls.com 초기 사이트 설계

## 목표

집에서 생기는 문제를 원인·확인·해결 순서로 안내하는 주택 관리 매뉴얼 사이트를 만든다.

## 구조

- Astro 정적 생성 사이트
- 콘텐츠는 `src/data`의 카테고리·가이드 데이터로 관리
- 공통 레이아웃에서 SEO, 헤더, 푸터, JSON-LD를 제공
- 홈은 문제 유형 탐색과 대표 매뉴얼로 진입시키고, 상세 페이지는 문서형 구조로 제공
- CSS는 자체 디자인 토큰과 모바일 우선 레이아웃으로 구성하며 UI 라이브러리는 사용하지 않음

## 디자인 원칙

아이보리 종이 배경, 잉크색 본문, 오렌지 안전 표시색, 청록 설비 표시색을 사용한다. 반복 카드 대신 목록·번호 매기기·점검표·주의 박스를 중심으로 구성한다.

## SEO와 접근성

semantic HTML, 명확한 heading 순서, skip link, 키보드 포커스, canonical/OG, sitemap/robots, WebSite/Article/Breadcrumb JSON-LD를 제공한다.
